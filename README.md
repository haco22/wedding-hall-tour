# 웨딩홀 투어 대시보드

iPad Safari용 웨딩홀 현장체크·견적·비교 대시보드입니다. GitHub Pages 배포용입니다.

## 현재 투어 일정

- 2026-09-17 17:00 · 마곡 보타닉파크 웨딩
- 2026-09-18 14:00 · 더컨벤션 송파문정
- 2026-09-18 17:00 · 웨딩스퀘어 강변

기존 대규모 후보 목록은 제거했고, 검색 입력 중에는 입력창 자체를 다시 렌더링하지 않아 iPad Safari 키보드/포커스가 유지되도록 수정했습니다.


## 예약 관리

- 전화 카드에서 방문 날짜와 시간을 함께 입력
- 별도 `예약목록` 탭에서 예약 일정을 한눈에 확인
- 앞으로 갈 일정은 가까운 날짜 → 빠른 시간순으로 자동 정렬
- 날짜와 시간이 모두 입력되면 미확인/방문 가능 상태는 예약완료로 정리
